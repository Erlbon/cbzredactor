**Downloads**
- `cbzredactor-setup.exe`: installs the program for you alone (no administrator rights), with a Start menu entry.
- `cbzredactor.exe`: one file, runs from anywhere.
- `cbzredactor-linux-x86_64.tar.gz`: the Linux build (added a few minutes after the release appears).

**A copy of an earlier version must be updated by hand this once**: download one of the files above. From this
release on, Help > Check for Updates installs new versions itself.

**In short**
- **Check for Updates installs new versions itself**, and there is a Windows installer.
- **Delete Files (Recycle Bin)**, and the Delete key asks: Remove from List, Delete Files or Cancel.
- **Lookups fill more**: Volume is the series' start year, GCD Count for ended series, Alternate Series and Age
  Rating; Comic Vine Auto looks up the rest of a series in one go.
- **Fixes from a full code review** (about 60 points): saving and archives, conversion and resize, lookups, Find
  Duplicates, Validate and Redact, the command line. A lookup that fails on one comic no longer loses the batch.

## 2026-11-28#02 -- redactor_common 2026-11-28-01

- The family's shared library moves to 2026-11-28-01 (one pin across the family). Its changes since 2026-11-27-08

## 2026-11-28#01 -- A failed lookup no longer loses the batch

- **A lookup that fails on one comic shows "(error)" on that row** (with the message in the details and the status
  line) instead of closing the lookup window and losing the results for every comic searched before it. The same goes
  for "Search This Item". This comes with redactor_common 2026-11-27#08.

## 2026-11-27#10 -- Command line and dialog fixes

- **Import Settings now changes the conversion settings after Preferences has been saved.** The whole conversion
  policy (when to convert, what happens to originals, the recent-file rule, the dry-run offer) is exported and
  imported; the quarantine and undo-log folders travel with the computer-only paths.
- **`rename -p ""` is refused** instead of renaming every file with the default pattern.
- **`set` accepts a plain decimal for CommunityRating only** ("3.5", not "0_1" or "1e0").
- **`redact` exits with 1 when a file could not be read**, like `info` and `set` do.
- **File and page names with `<` or `>` are shown as typed** in the page viewer, the Duplicates window and the
  credit-page windows.
- **The Collection Report's MB and Pages columns sort as numbers.**
- **Save List protects against spreadsheet formulas.** A cell starting with `=`, `+`, `-` or `@` gets a leading
  single quote.

## 2026-11-27#09 -- Lookup fixes

- **An odd answer from Comic Vine, GCD or Bedetheque no longer crashes the lookup.** A reply of the wrong shape is
  reported as an unreadable answer, or its odd parts are skipped, so the results already found are kept.
- **Comic Vine summaries show `&` and `'` properly and keep paragraphs and list items apart.**
- **Comic Vine dates with an unknown month or day** ("1985-00-00") leave Month and Day empty instead of writing 0.
- **A slash in the series or number ("Batman/Superman", issue 1/2) no longer breaks the GCD online search.** A year
  like "86" no longer sends the same GCD request twice.
- **The GCD login is only sent to www.comics.org over https.** Covers and any other address named in an answer are
  fetched without it, and links to other sites in an answer are not followed.
- **The manga lookup no longer writes the series' start date** as Year, Month and Day of every volume. "J.K. Rowling"
  stays as written, and underscores or asterisks inside words of a description are kept.
- **ComicRack import accepts months 1 to 12 only** (a Month of 20 is ignored).
- **Remove Account in API Keys waits for Save**, so Cancel keeps the account.
- **The Comic Vine browser reads and decodes each file's first page in the background.** The cover box says
  "Loading..." and a huge scan no longer freezes the window.

## 2026-11-27#08 -- Validate, Redact and scene name fixes

- **Fix ComicInfo issues no longer cuts real subtitles.** "Hulk (The Missing Years)" or "Batman (Variant Edition)" keep
  their brackets; only known scene tags, format words and release-group tags are removed from Title and Series.
- **A Year, Month or Day with spaces or line breaks round it is trimmed, not erased.**
- **File name number "0a" stays "0a"** in Parse Filename and Redact (it became "a").
- **One Comic Vine "not found" no longer stops Comic Vine for the whole Redact run.** Only a network error, a bad key
  or the rate limit does.
- **`redact --trash-dir` now says where the original went** instead of "Recycle Bin".
- **A learned credit-pages file that cannot be read for a moment is no longer overwritten.** New pages wait in memory
  and are saved with the old ones once the file can be read.

## 2026-11-27#07 -- Main window and panel fixes

- **Undo after Save no longer hides unsaved changes.** If a Save came after the edit you undo, the file still holds
  the newer values, so the comic is now marked Modified and Save All writes the undone values.
- **Selecting a comic no longer rewrites its Summary or Community Rating.** Only fields you changed in the panel
  are written back, so a rating of 3.75 or a Summary with trailing spaces stays as it was.
- **Restore from History asks before reloading a comic with unsaved edits.** Answering No keeps those edits.
- **Undo and Redo keep text you typed in the panel but have not committed yet.**
- **Opening a file that is already in the list no longer adds a second row.** The status bar says how many were
  already loaded, and edits and Delete now always act on the right row.
- **Apply with every row unticked in the overwrite review now counts as Cancel.** Nothing is written and what you
  typed stays in the panel (also for Parse Filename and Read Filename Tags).
- **Save All no longer freezes the window.** Each file is written in the background, the progress dialog keeps
  moving and Cancel responds at once (the file in progress finishes first).
- **The Preview reader follows a changed page list.** After Remove Pages, Clean Up or a rename, the page shown
  and the name displayed stay in step.

## 2026-11-27#06 -- Conversion and resize fixes

- **Converting a CBR, CB7 or CBT no longer loses a page to a name clash.** Two pages whose names differ only in
  capitals (`A.jpg`, `a.jpg`) overwrite each other when unpacked on Windows. The page count is now taken from the
  archive's own list, so the conversion is refused with a clear message and the original is kept.
- **Resize keeps the colour profile and the rotation of a page.** A page with an embedded colour profile keeps it,
  and a page that relied on its EXIF rotation is turned for real instead of showing sideways.
- **Resize settings stay within the Resize dialog's limits.** An imported settings file or hand-edited ini can no
  longer set a width of 1 pixel (or a quality or height outside the dialog's range) for conversions, the command
  line and Redact.

## 2026-11-27#05 -- Find Duplicates fixes

- **Find Duplicates no longer groups a whole manga series.** Comics sharing a series page as their Web link (the
  manga lookup writes one for every volume) are no longer treated as copies of one comic and ticked for the Recycle
  Bin. Only a link to a single Comic Vine, GCD or Bedetheque issue still groups by link.
- **Find Duplicates is faster on large collections and shows a progress dialog.** Only comics with similar pages are
  compared, and the comparison runs in the background with a Cancel button.

## 2026-11-27#04 -- Save and archive fixes

- **Saving keeps the page list of a ComicInfo.xml that declares a namespace.** The Pages block is no longer
  rewritten as `ns0:Pages`, which other readers could not find.
- **AVIF, JXL, HEIC and TIFF pages count as pages.** Such comics no longer load with 0 pages, and a save no longer
  writes PageCount 0.
- **A repeated field keeps its first copy,** as the other Redactor tools read it, instead of the last.
- **Resize no longer leaves the old page sizes in ComicInfo.xml.** The width, height and size of each page entry
  are dropped, since they no longer match.
- **Odd digits (superscripts, circled numbers) no longer crash page names, Validate and Fix, or the Collection
  Report.**
- **A ComicInfo.xml with thousands of nested elements is refused on load** with a message, instead of loading and
  then crashing every save.
- **Save As onto the comic's own file is treated as a normal save,** so the row is no longer left marked Modified.
- **A huge ComicInfo.xml or first page is no longer unpacked into memory before its size is checked.**

## 2026-11-27#03 -- Save and scan fixes -- redactor_common 2026-11-27-07

- **A stray control character no longer crashes Save.** Text pasted into a field with a hidden character (a form
  feed from a PDF, for example) now gives a "Save Failed" box that says the field cannot be stored, and the file is
  left untouched.
- **One huge page no longer stops a whole scan.** A single oversized page (a giant map, say) is skipped by Scan
  Collection Folder, Find Duplicates and the credit-page scan instead of ending the run for every other comic.
- Moved to the newest shared code (redactor_common 2026-11-27-07).

## 2026-11-27#02 -- Shared-code update -- redactor_common 2026-11-27-06

- **A file name is never just a Windows device name.** The shared code's filename tidy-up now puts "_" in front of
  CON, AUX, NUL, COM1 and the like, as the rename pattern already did, so such a name can no longer reach the disk.
- Also in the shared update, not used by this app: the folder-cover finder no longer takes Windows Media Player's
  small thumbnail (`albumartsmall.jpg`) as an album's cover.

## 2026-11-27#01 -- Safer saving, deleting and renaming -- redactor_common 2026-11-27-04

- **Save As over an existing file still works**, after you confirm the replace in the file dialog. The shared
  code now refuses to overwrite any other file on its own, so Save As says explicitly that you agreed.
- **Search & Replace on the file name checks the new name first.** A name Windows would reject (a slash, a
  reserved name such as CON, a trailing dot) is listed in the "Some Files Failed" message and the file keeps its
  old name, instead of the rename failing half way.
- **Recycle Bin on Windows needs the modern back-end.** The app now installs and bundles pywin32 for it. Without
  it the shared code refuses to delete, because the old back-end deleted for good a file too big for the Recycle
  Bin without saying so.
- **Export/Import Settings:** a Redact recipe in a settings file now lands on an app that is still on the default
  recipe (it was silently skipped). Names containing "key", "auth" or "cookie" are no longer exported, and a
  value of the wrong type in a file is ignored.
- A failing History file no longer shows a warning; the change is just not recorded and saving carries on.

## 2026-11-26#02 -- Delete Files (Recycle Bin), and the Delete key asks what you mean

- **New: File > Delete Files (Recycle Bin)...** (Shift+Delete, also in the right-click menu). It asks first, then sends the selected files to the Recycle Bin and takes them off the list. A file with unsaved changes is not deleted: it stays in the list and the warning says so. The status bar tells you how many went.
- **The Delete key asks: Remove from List, Delete Files (Recycle Bin) or Cancel.** Before, Delete only took the comic off the list and left the file on disk, which is not what most people expect. Remove from List is the default button, so Delete then Enter never deletes a file. Choosing Delete Files sends the files to the Recycle Bin at once (no second question). File > Remove from List and File > Delete Files still act at once from the menu, and Remove from List has no shortcut now.
- The question comes from redactor_common 2026-11-26-02. The previous release already moved this app from 2026-11-21-02 to that tag, so the pin does not change here.

## 2026-11-26#01 -- Check for Updates installs the new version itself; a Windows installer -- redactor_common 2026-11-26-02

- **Help > Check for Updates installs the update** instead of only opening the download page. The app is on the
  Redactor family's update framework (redactor_common docs/update-framework.md): every release carries an
  `update-manifest.json` naming each download with its size and checksum, and every copy says how it was put on the
  PC. The portable `cbzredactor.exe` replaces itself (the old one is kept as `cbzredactor.exe.old` until the next
  start) and starts again; an installed copy runs the new installer silently and starts again. When it cannot update,
  it says why, with a Copy details button, and still offers the download page.
- **A Windows installer**, `cbzredactor-setup.exe`: per user, no administrator rights, into
  `%LOCALAPPDATA%\Programs\The CBZ Redactor`, with a Start menu entry. The one-file `cbzredactor.exe` stays the
  portable download.
- **A copy on an older version must be updated by hand once**: download this release from the release page. Its
  Check for Updates cannot read the new releases' manifest (decided for the whole family: no bridge for old copies).
- The command line has `cbzredactor --check-update [--release-tag vX]` (prints what this copy would do, as JSON;
  changes nothing) and `--update` (does it without a window), for the release gate.
- Releases are now made with redactor_common's release tool (`pyproject.toml`), which builds the exe, the installer
  and the manifest, publishes a pre-release, checks the update from the previous release, and only then makes it
  Latest. The GitHub workflow no longer builds the Windows exe (its upload would replace the file the manifest
  pins); it adds only the Linux download, when the release is published. The Linux build cannot replace itself: it
  says so and opens the release page.
- Shared code moved from redactor_common 2026-11-21-02 to 2026-11-26-02. For this app: `%dummy%` in a Parse Filename
  pattern skips a piece of text (and may be used more than once). The rest is MusicBrainz and Discogs lookups, which
  this app does not use, and the Delete key's new question, which applies only to apps with Delete Files.

## 2026-11-25#01 -- Auto-Number opens on Number

## 2026-11-23#01 -- Comic Vine: Auto for the rest of the series

- **▶| Auto**, a new green player button between ▶ and ▶▶ in Look Up via Comic Vine. Once you have found the right series, it uses the shown issue and then does the same for each following file: the issue with that file's number in the same series. No more pressing ▶ for every issue of a long run.
- It stops by itself, and leaves that file on screen to do by hand, when a file has another series name, a number the series does not have, no number, or a year more than one year from the issue's cover date. While it runs, ▶| becomes a pause button; pause, ◀◀ or Search takes over at any time.
- One file a second at most, and only after the previous file's details are back, to stay under Comic Vine's speed limit.
- Everything still goes through the usual overwrite review before anything is written.

## 2026-11-21#06 -- GCD: Count, Alternate Series, Age Rating

- **Count**, for a series that has ended: Preacher gives 66. A series still running gets no Count, because the number would be out of date next month. Variant covers are not counted as issues (Thor 2018 is 16 issues, not its 55 covers).
- **Alternate Series** with a legacy number: Thor (2018) #1 gives Number 1, Alternate Series Thor, Alternate Number 707.
- **Age Rating**, from GCD's rating text: Teen+ / T+ / Teen and the like give Teen; Mature Readers, Parental Advisory and PSR give Mature 17+; Adults Only gives Adults Only 18+; All Ages and Rated A give Everyone. A Comics Code seal or any other text writes nothing.
- The online GCD lookup now also fills Black & White, like the local one.
- Fix: the online lookup could give the publisher itself as Imprint ("Marvel" for Marvel Worldwide Inc.).

## 2026-11-21#05 -- Lookups fill more fields

- **ComicRack Library** now gives back everything of yours it stores: Teams, Locations, Story Arc, Alternate Series / Number / Count, Count, Format, Age Rating, Manga, Black & White. Before, it stored them but read back only the Web link. Convert your library again (Settings > ComicRack Library) to also get Imprint, Series Group, Main Character or Team, Tags and Translator.
- **GCD (online and local database):**
  - **Cover Artist**, from the cover's own credits.
  - **Translator.** Translators used to land in **Writer**: GCD marks them in the script credit ("translation", "oversetter", "Übersetzung", "vertaling"...). They now go to Translator only.
  - **GTIN**, from the ISBN, otherwise the barcode (the small issue-number add-on is dropped).
  - **Imprint**, from GCD's brand (Vertigo, Marvel Knights, Icon). A brand that is just the publisher itself (DC, Marvel, Image) is left out.
  - **Legacy numbers are split.** "1 (707)" used to go into Number as it is; now Number is 1 and Alternate Number is 707.
  - The local database also fills **Black & White** from the series' colour note.
- **Bedetheque:** GTIN (EAN/ISBN) and Community Rating. Not yet checked against a live page: Bedetheque's bot check currently stops the lookup's own fetch.
- **Manga:** Characters from AniList, main characters first, at most 10.

## 2026-11-21#04 -- Lookups fill Volume

- Comic Vine, both GCD lookups (online and local database), the ComicRack Library lookup, and Redact's Comic Vine step now fill **Volume** with the year the series started (for example 1986). That is the ComicRack and Comic Vine convention, and what ComicTagger and Kavita read. Before, no lookup wrote Volume. Comic Vine already fetched the year and threw it away.
- The ComicRack Library lookup gives your own Volume when it is a year; otherwise, the year of the series' first issue.

## 2026-11-21#03 -- Include Subfolders: Open Folder follows the checkbox

- Open Folder and Refresh List now do what the Include Subfolders checkbox shows. Before, they re-read the saved setting instead. When the settings file next to the exe could not be written (for example the exe in a read-only folder), the saved value stayed "on", and unticking the box changed nothing: subfolders were always included.
