**Downloads**
- `cbzredactor-setup.exe`: installs the program for you alone (no administrator rights), with a Start menu entry.
- `cbzredactor.exe`: one file, runs from anywhere.
- `cbzredactor-linux-x86_64.tar.gz`: the Linux build (added a few minutes after the release appears).

**A copy of an earlier version must be updated by hand this once**: download one of the files above. From this
release on, Help > Check for Updates installs new versions itself.

Everything since v2026-11-21-02 (8 versions):

## 2026-11-26#02 -- Delete Files (Recycle Bin), and the Delete key asks what you mean

- **New: File > Delete Files (Recycle Bin)...** (Shift+Delete, also in the right-click menu). It asks first, then sends the selected files to the Recycle Bin and takes them off the list. A file with unsaved changes is not deleted: it stays in the list and the warning says so. The status bar tells you how many went.
- **The Delete key asks: Remove from List, Delete Files (Recycle Bin) or Cancel.** Before, Delete only took the comic off the list and left the file on disk, which is not what most people expect. Remove from List is the default button, so Delete then Enter never deletes a file. Choosing Delete Files sends the files to the Recycle Bin at once (no second question). File > Remove from List and File > Delete Files still act at once from the menu, and Remove from List has no shortcut now.
- The question comes from redactor_common 2026-11-26-02. The previous release already moved this app from 2026-11-21-02 to that tag, so the pin does not change here.

## 2026-11-26#01 -- Check for Updates installs the new version itself; a Windows installer -- redactor_common 2026-11-26-02

- **Help > Check for Updates installs the update** instead of only opening the download page. The app is on the
  Redactor family's update framework (redactor_common docs/update-framework.md): every release carries an
  `update-manifest.json` naming each download with its size and checksum, and every copy says how it was put on the
  PC. The portable `cbzredactor.exe` replaces itself (the old one is kept as `cbzredactor.exe.old` until the next
  start) and starts again; an installed copy runs the new installer silently and starts again. When it cannot update,
  it says why, with a Copy details button, and still offers the download page.
- **A Windows installer**, `cbzredactor-setup.exe`: per user, no administrator rights, into
  `%LOCALAPPDATA%\Programs\The CBZ Redactor`, with a Start menu entry. The one-file `cbzredactor.exe` stays the
  portable download.
- **A copy on an older version must be updated by hand once**: download this release from the release page. Its
  Check for Updates cannot read the new releases' manifest (decided for the whole family: no bridge for old copies).
- The command line has `cbzredactor --check-update [--release-tag vX]` (prints what this copy would do, as JSON;
  changes nothing) and `--update` (does it without a window), for the release gate.
- Releases are now made with redactor_common's release tool (`pyproject.toml`), which builds the exe, the installer
  and the manifest, publishes a pre-release, checks the update from the previous release, and only then makes it
  Latest. The GitHub workflow no longer builds the Windows exe (its upload would replace the file the manifest
  pins); it adds only the Linux download, when the release is published. The Linux build cannot replace itself: it
  says so and opens the release page.
- Shared code moved from redactor_common 2026-11-21-02 to 2026-11-26-02. For this app: `%dummy%` in a Parse Filename
  pattern skips a piece of text (and may be used more than once). The rest is MusicBrainz and Discogs lookups, which
  this app does not use, and the Delete key's new question, which applies only to apps with Delete Files.

## 2026-11-25#01 -- Auto-Number opens on Number

- **Edit > Auto-Number...** now opens with **Number** chosen as the field, instead of Title. The other fields are still in the list.

## 2026-11-23#01 -- Comic Vine: Auto for the rest of the series

- **▶| Auto**, a new green player button between ▶ and ▶▶ in Look Up via Comic Vine. Once you have found the right series, it uses the shown issue and then does the same for each following file: the issue with that file's number in the same series. No more pressing ▶ for every issue of a long run.
- It stops by itself, and leaves that file on screen to do by hand, when a file has another series name, a number the series does not have, no number, or a year more than one year from the issue's cover date. While it runs, ▶| becomes a pause button; pause, ◀◀ or Search takes over at any time.
- One file a second at most, and only after the previous file's details are back, to stay under Comic Vine's speed limit.
- Everything still goes through the usual overwrite review before anything is written.

## 2026-11-21#06 -- GCD: Count, Alternate Series, Age Rating

- **Count**, for a series that has ended: Preacher gives 66. A series still running gets no Count, because the number would be out of date next month. Variant covers are not counted as issues (Thor 2018 is 16 issues, not its 55 covers).
- **Alternate Series** with a legacy number: Thor (2018) #1 gives Number 1, Alternate Series Thor, Alternate Number 707.
- **Age Rating**, from GCD's rating text: Teen+ / T+ / Teen and the like give Teen; Mature Readers, Parental Advisory and PSR give Mature 17+; Adults Only gives Adults Only 18+; All Ages and Rated A give Everyone. A Comics Code seal or any other text writes nothing.
- The online GCD lookup now also fills Black & White, like the local one.
- Fix: the online lookup could give the publisher itself as Imprint ("Marvel" for Marvel Worldwide Inc.).

## 2026-11-21#05 -- Lookups fill more fields

- **ComicRack Library** now gives back everything of yours it stores: Teams, Locations, Story Arc, Alternate Series / Number / Count, Count, Format, Age Rating, Manga, Black & White. Before, it stored them but read back only the Web link. Convert your library again (Settings > ComicRack Library) to also get Imprint, Series Group, Main Character or Team, Tags and Translator.
- **GCD (online and local database):**
  - **Cover Artist**, from the cover's own credits.
  - **Translator.** Translators used to land in **Writer**: GCD marks them in the script credit ("translation", "oversetter", "Übersetzung", "vertaling"...). They now go to Translator only.
  - **GTIN**, from the ISBN, otherwise the barcode (the small issue-number add-on is dropped).
  - **Imprint**, from GCD's brand (Vertigo, Marvel Knights, Icon). A brand that is just the publisher itself (DC, Marvel, Image) is left out.
  - **Legacy numbers are split.** "1 (707)" used to go into Number as it is; now Number is 1 and Alternate Number is 707.
  - The local database also fills **Black & White** from the series' colour note.
- **Bedetheque:** GTIN (EAN/ISBN) and Community Rating. Not yet checked against a live page: Bedetheque's bot check currently stops the lookup's own fetch.
- **Manga:** Characters from AniList, main characters first, at most 10.

## 2026-11-21#04 -- Lookups fill Volume

- Comic Vine, both GCD lookups (online and local database), the ComicRack Library lookup, and Redact's Comic Vine step now fill **Volume** with the year the series started (for example 1986). That is the ComicRack and Comic Vine convention, and what ComicTagger and Kavita read. Before, no lookup wrote Volume. Comic Vine already fetched the year and threw it away.
- The ComicRack Library lookup gives your own Volume when it is a year; otherwise, the year of the series' first issue.

## 2026-11-21#03 -- Include Subfolders: Open Folder follows the checkbox

- Open Folder and Refresh List now do what the Include Subfolders checkbox shows. Before, they re-read the saved setting instead. When the settings file next to the exe could not be written (for example the exe in a read-only folder), the saved value stayed "on", and unticking the box changed nothing: subfolders were always included.
